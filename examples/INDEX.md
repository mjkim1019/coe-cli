# Examples Index

This directory contains hands-on examples and tutorials for using the Swing CLI.

## 📚 Available Examples

### 1. Architect Mode Demo

**Location:** `architect_mode_demo/`

**Description:** Complete walkthrough of the Architect Mode feature - AI-powered task orchestration that breaks down natural language requests into executable plans.

**Files:**
- 📖 **[QUICK_START.md](architect_mode_demo/QUICK_START.md)** - Get started in 3 steps (1 minute)
- 📘 **[README.md](architect_mode_demo/README.md)** - Complete walkthrough with examples
- 🎨 **[VISUAL_GUIDE.md](architect_mode_demo/VISUAL_GUIDE.md)** - Visual workflow diagrams
- 📄 **[customer_schema.sql](architect_mode_demo/customer_schema.sql)** - Sample data file

**Quick Access:**
```bash
cd examples/architect_mode_demo
cat QUICK_START.md  # Start here!
```
